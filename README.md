# Fin de Poste

Jeu façon Vampire Survivors sur le quai de nuit : tiens dix minutes jusqu'à la fin du poste.

- Un seul fichier : `index.html` (HTML, CSS et JavaScript, sans dépendance).
- Se joue au clavier : ZQSD ou flèches pour bouger, Échap pour la pause, Q/D + Espace pour choisir une carte.
- La progression (caisse, vestiaire, personnages, lieux) est sauvegardée dans le navigateur.
- Mise en ligne : Netlify, dossier publié = racine du dépôt, aucune commande de build.
